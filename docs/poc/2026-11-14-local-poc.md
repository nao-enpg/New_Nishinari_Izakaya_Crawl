## 分かったこと（計画・CLAUDE.md に反映済み、または反映が必要）

1. **npm ではなく pnpm を使う**。npm 10.9 は、この依存関係で `Cannot read properties of null (reading 'edgesOut')` で落ちた。
2. **Vitest は 5.1 を使える**。`@cloudflare/vitest-pool-workers` は非推奨になり、後継の `@cloudflare/vitest-plugin@1.8.2` が Vitest 5 に対応している（レビューの「Vitest 5 は使えない」は古い情報）。
3. **`npx prisma` は 8.0 RC を取ってくる**。実際に、インストールが途中で失敗した状態で `npx prisma` を実行したら 8.0.0-rc.33 が入った。`pnpm exec prisma` を使う。
4. この作業環境では `binaries.prisma.sh` に届かないので、`prisma migrate diff` は CI か手元の PC で実行する。`prisma generate` は `PRISMA_SCHEMA_ENGINE_BINARY=/bin/true` を付ければ動く。
5. **Vitest で Prisma の WASM を読むには**、`cloudflareTest` に `wrangler.configPath` を渡す必要があった（`miniflare` の設定だけでは `.wasm?module` を扱えない）。
6. テストのたびに D1 が初期化されるわけではない。テストの最初に表を空にする必要があった。
7. 多言語化は、現行の文言が100件程度で `?locale=` 方式なので、**ライブラリを使わない型付き辞書**が最も単純で安全。候補として Paraglide JS 3 も残す。
