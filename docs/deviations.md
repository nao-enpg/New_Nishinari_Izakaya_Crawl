# 差分台帳 v0.1（現行との違い）

新しい実装で、現行（Rails 版）と違う振る舞いにするものの一覧。ここに無い違いは不具合として扱う。
各項目は Nao の承認で確定する（「状態」列: 承認待ち → 承認 / 却下）。「要確認」は、各機能の clarify で決める。
現行の振る舞いの詳細は `legacy/` を参照。

- **ID は採番したときのまま固定する**。分類が変わって別の表に移しても、番号は変えない。欠番は再利用しない。
- 「承認済み」の出典「計画」は `plan.md` v0.4 の第0章（決定済みの前提）を指す。
- 「再現済み」は独立検証（`review/deliverables-review.md`）で現行と同じ版の CSS や HTML を組み立てて確かめたもの。「推定」はコードとライブラリのソースから判断したもの。

改訂履歴
- v0.1（2026-11-14）: 独立検証の指摘を反映した。
  - 追加: D-024（検索の全列検索）、D-025（誰でもアカウントを作れる）、Q-009、Q-010、C-016
  - 修正: D-013、D-016、D-017、D-019、D-020、D-021、D-X01、D-X06 の記述
