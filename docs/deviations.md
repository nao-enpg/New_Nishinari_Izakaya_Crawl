# 差分台帳 v0（現行との違い）

新しい実装で、現行（Rails 版）と違う振る舞いにするものの一覧。ここに無い違いは不具合として扱う。
各項目は Nao の承認で確定する（「状態」列: 承認待ち → 承認 / 却下）。「要確認」は、各機能の clarify で決める。
現行の振る舞いの詳細は `legacy/` を参照。
